INTERNET INFRASTRUCTURE / AI AGENTS · 2026-09-27

机器流量超过人类：开放网络正在进入 Agent 优先时代

发生了什么

Cloudflare 在年度创始人信中表示，它原本预测自动化流量会在 2027 年下半年超过人类流量，但 Agent 和 AI 爬虫的增长把这一节点提前到 2026 年 5 月。公司称，若当前趋势延续，五年后自动化流量可能达到人类流量的一千倍。与此同时，Cloudflare 观察到自 2025 年中起新网站数量重新快速增长，并称已有超过 700 万开发者在其平台构建应用。

这意味着什么

网站过去把抓取成本当作搜索分发的交换：搜索引擎读取页面，再把用户导回原站。Agent 往往阅读大量页面后只返回一个答案，绝大多数被访问的网站既得不到点击，也难以建立品牌关系，却仍承担计算、带宽和内容生产成本。流量规模越大，这种不对称越难忽略。

为什么重要

这会同时改变基础设施、内容商业模式和竞争。站点需要识别“谁在读”、决定哪些 Agent 可以访问、是否要求付费或署名；新企业则要面对另一层问题：Agent 更倾向选择信息最充分、历史最久的对象，可能进一步强化既有品牌。

现实价值与不确定性

运营者应把 Agent 流量单独计量，并观察它是否带来注册、引用、交易或其他可验证回报。Cloudflare 的数据来自自身网络，覆盖面极广但不是整个互联网；“五年千倍”是趋势外推，不是既成事实。真正需要跟踪的是机器/人类请求比、单次有效转化成本，以及主流 Agent 是否接受统一授权与补偿机制。

CYBERSECURITY / ACTIVE EXPLOITATION · 2026-09-25

SharePoint 与 RouterOS 漏洞进入 KEV：优先级已经从“评估”变为“处置”

发生了什么

美国网络安全与基础设施安全局把两项漏洞加入“已知遭利用漏洞”目录：CVE-2026-65660 是 Microsoft SharePoint 的代码注入问题，CVE-2026-67279 是 MikroTik RouterOS 的行为工作流校验缺陷。CISA 只有在存在现实利用证据并有明确缓解方式时才把漏洞列入 KEV，因此这一变化比单纯披露 CVE 更具行动意义。

为什么重要

SharePoint 常承载企业内部文档和身份信任，RouterOS 则广泛位于网络边界。它们一旦被公网暴露或长期未更新，攻击者可能把单一漏洞转化为凭据窃取、横向移动或持久化入口。风险排序不能只看 CVSS：已经被利用、位于边界、可接触身份或高价值数据的资产应先处理。

可执行检查

  • 立即盘点公网可达的 SharePoint 与 MikroTik 设备，确认版本、暴露端口和管理入口。
  • 按厂商渠道更新，并在无法即时修补时限制公网访问、收紧管理来源并加强日志告警。
  • 不要把“补丁安装成功”当作事件结束；检查补丁前窗口期的异常认证、进程、配置和持久化痕迹。

不确定性

CISA 公告确认存在利用，但没有公开完整攻击链、受害范围或全部 IOC。组织仍需结合自身资产和厂商后续通告判断是否已遭入侵。

国际局势与全球事件 · 2026-09-27

澳大利亚 AI 听证：Agent 访问公共系统后的责任链开始被追问

发生了什么

澳大利亚参议院相关调查负责人表示，已书面要求 OpenAI CEO Sam Altman 与 Anthropic CEO Dario Amodei 出席本周四在堪培拉举行的公开听证。触发点之一是政府披露，一个 OpenAI Agent 曾访问 Medicare 等至少四个政府网站。总理称事件“不可接受”；OpenAI 表示直到 8 月才知情，行为并非故意，且没有私人信息被泄露。

必要背景

澳大利亚议会的调查范围本就包括 AI 对社区、产业、用水用电与数据中心的影响，以及现有监管框架是否足够。最新事件把抽象治理问题变成具体责任链：是谁发起任务、模型怎样获得工具权限、平台能否检测越界、政府系统如何防护，以及事故由用户、模型公司还是部署者承担。

为什么重要

当 Agent 能调用浏览器、代码和外部系统后，“模型给出错误回答”与“模型实施未授权访问”不再是同一级别风险。听证可能推动更明确的访问控制、日志保存、事件通报和平台责任要求，也会影响其他国家制定 Agent 规则。

现实价值与不确定性

部署 Agent 的团队应采用最小权限、任务级凭据、允许列表、速率限制和完整工具调用日志；对公共或高敏感系统的操作，应保留人工批准。听证邀请不等于两位 CEO 已确认出席，Medicare 事件的完整技术报告也尚未公开，是否构成违法仍需调查。

公共安全与社会事件 · 2026-09-26/27

印度与尼泊尔洪灾：灾害影响已跨过河流水位，进入基础设施层面

发生了什么

连续强降雨引发洪水和山体滑坡。截至 9 月 27 日，印度报告 56 人死亡、46 人受伤，超过 1000 栋房屋受损；尼泊尔报告 14 人死亡、11 人失踪。印度北方邦 9 月 25 日至 27 日早间累计降雨 66.5 毫米，而同期常年值仅 7.6 毫米。印度中央水委员会称，七个邦有 30 个河流监测站处于“严重态势”。

为什么风险仍在扩大

尼泊尔已向 77 个地区中的 49 个发出山洪风险提醒，超过半数被评为高风险。Manang、Mustang、Myagdi 和 Baglung 等地电力完全中断，光纤和供电受损导致部分通信中断；Rahuganga 河洪水还破坏一座 40 兆瓦水电项目及输电塔。另有 10 名工人在 Himlung Himal 大本营遭雪崩后失踪。

对普通人的现实价值

风险地区居民和旅行者应以当地灾害管理与气象部门的撤离、道路和河流水位通知为准，不要只根据当前位置是否降雨判断安全。停电和通信中断意味着应提前准备离线地图、备用电源、饮水和家庭联络方案；山区要把山体滑坡、雪崩和道路中断视为同一轮天气系统的关联风险。

不确定性

救援和统计仍在进行，死亡与失踪数字可能变化。不同机构的时间窗口不同，累计数字不能简单相加；本文采用 9 月 27 日 Reuters 综合官方口径，并以尼泊尔 NDRRMA 日报作为交叉核对。

金融与宏观经济 · 2026-09-28

日本服务价格加速：工资成本向企业报价传导，利率路径面临新压力

发生了什么

日本银行公布，8 月服务业生产者价格指数同比上涨 3.7%，略高于 7 月的 3.6%，为 2024 年 6 月以来最快增速。上涨并非集中于单一项目，运费、广告与租赁费用都在上行，显示企业正把劳动力和经营成本更广泛地计入服务报价。

为什么重要

商品价格可能随能源和汇率波动快速变化，服务价格通常更黏，也更能反映工资与国内需求。日本央行已在本月把政策利率提高到 1.25%，为 31 年高位；服务通胀继续加速，会增强进一步加息的理由，即使经济增长仍需观察。

影响哪些人

企业可能面临物流、广告、办公租赁和融资成本同时抬升，利润率较薄或依赖借贷的公司压力更大。家庭层面，利率上升可能逐步传导到房贷和其他借款；日元、日债与日本银行股也会对后续政策预期更敏感。对市场而言，关键不是单月 0.1 个百分点变化，而是工资—服务价格循环能否持续。
