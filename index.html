PLATFORM SECURITY / IDENTITY · 2026-09-24

GitHub 为高风险操作加入“在场证明”

发生了什么

GitHub Enterprise Cloud 现在可要求成员在执行高影响操作前进行交互式重新认证或 MFA 挑战。它扩展了 GitHub 原有 sudo 模式，把验证从“登录时做一次”推进到“关键动作发生时再确认”。

为什么重要

长时间有效的浏览器会话、被盗 token 和自动化 Agent 都可能在身份仍有效时执行破坏性操作。Proof of presence 不能消除账号被盗，但能在删除资源、修改安全策略等动作前增加一道与当前操作者绑定的检查。

对开发团队的现实价值

对于允许 Coding Agent 修改仓库、发版或管理 Actions secrets 的企业，这类机制意味着权限模型需要区分“可以访问”和“此刻可以完成高风险动作”。建议把生产发布、权限提升、密钥变更和大规模删除纳入 step-up authentication。

AGENT SECURITY · 2026-09-23/24

Muse 漏洞说明：Agent 的输入通道就是新的控制面

发生了什么

安全研究者 Patrick Wardle 发现，macOS 上的恶意本地程序可修改 Muse 的未公开设置，将转录处理从 Meta 服务重定向到攻击者控制的端点。被篡改的输入随后可能诱导 Agent 执行拍照、写文件等动作。Meta 已发布热修复，并强调利用前提是设备上已有恶意代码。

这件事到底意味着什么

传统应用把转录视为内容输入；Agent 应用却会把输入转成行动。一旦输入链被劫持，攻击者获得的不是一段错误文本，而可能是对工具与设备权限的间接控制。因此转录、浏览器内容、邮件和网页都应按不可信指令处理。

可执行检查

  • 敏感工具调用要求明确的人类确认。
  • Agent 配置文件必须限制其他进程修改。
  • 把“本地已有恶意代码”纳入威胁模型，而不是当成可忽略前提。

CODING AGENT / DATA BOUNDARY · 2026-09-23

ZCode 事件把“代码索引”的真实数据路径暴露出来

发生了什么

Z.ai 暂停 ZCode 部分能力，此前用户发现默认开启的 Codebase Indexing 会把本地代码库上传到云端。公司道歉并称已修补问题，同时承诺建立持续的安全披露与响应流程。

为什么重要

代码库经常包含未发布产品逻辑、客户信息、内部接口、配置和凭据。即使上传目的是向量化索引，只要用户没有获得清晰告知，企业就无法判断数据驻留、跨境传输、保留期限与模型训练边界。

对你的 Agent 项目的启示

内网部署 OpenClaw 或 Hermes 时，索引与推理应分开设计：索引优先本地完成，外发时只发送最小必要片段；敏感目录默认排除，并记录每次检索向模型提供了哪些文件。

也门粮食危机：港口与援助资金决定平民能否获得食物

发生了什么

WFP 在联合国大会期间表示正扩大也门援助。持续冲突已造成大规模流离失所，超过 1800 万人面临粮食不安全，数百万儿童营养风险突出。也门约九成粮食依赖进口，使港口和机场的可用性格外关键。

冲突地区统计随人口移动快速变化，具体数字可能修订；但进口依赖、援助缺口和港口受阻三个结构性风险已经明确。
